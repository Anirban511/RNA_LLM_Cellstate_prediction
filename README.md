# RNA_LLM_Cellstate_prediction
To determine CELL STATE from RNA Sequence using cutting edge BioBERT Model
This project is undertaken by Anirban Pal of IIT Kharagpur of BSBT Dept. 
The purpose of this project is to accurately determine Cell States based on the RNA Sequence of the genomic data available by fine tuning BioBERT model.
Convert RNA Sequence to Vectors and tokenise them then add one hot encoder and fusion layers to ouput by concatenating results and finally a prediction by softmax function.
